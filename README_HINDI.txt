SWACHH SULTANPUR ANDROID APK PROJECT

IMPORTANT:
1. ZIP ko extract karein.
2. Is ZIP ke andar jo files/folders hain, un sab ko GitHub repository ke ROOT mein upload karein.
3. Root par app folder, .github folder, build.gradle, settings.gradle aur gradle.properties dikhne chahiye.
4. GitHub Actions mein Build Swachh Sultanpur APK workflow khud chalega.
5. Green success hone par run ke Summary mein Artifacts se Swachh-Sultanpur-debug-apk download karein.
6. ZIP extract karke app-debug.apk phone mein install karein.

Existing Apps Script URL MainActivity.java mein rakha gaya hai.
Camera/gallery chooser aur WebView geolocation permission handling shamil hai.

NOTE:
Build successful hona aur phone par GPS/camera ka actual chalna alag cheezein hain.
APK ko Android phone par install karke location, camera, gallery aur photo upload test zaroor karein.
Google Apps Script deployment ko access permission aur HTTPS ke saath available rehna chahiye.
